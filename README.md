A one-line entry for the make.fun "Fortune Cookie for the Liquidated
Trader" bounty: a Python program that writes a single fortune-cookie
line — cracked open at 3am by a crypto trader whose position just got
liquidated — to `/output/entry.txt`.

The cookie keeps its promise, technically. The wealth really did
approach. It just took one look at the portfolio and kept walking.

Run it with `python3 main.py` (set `MAKEFUN_OUTPUT_DIR` to change where
`entry.txt` lands).
